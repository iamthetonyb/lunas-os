# Luna's OS

Welcome to Luna's OS repository!

## Getting Started

### Prerequisites

- Git installed on your local machine
- A GitHub account
- Write access to this repository (or create a fork)

### Uploading Your Local Files

If you want to upload files from your local storage to this repository, you'll need to authenticate with GitHub. We've created a comprehensive guide to help you:

**📖 [SSH Setup Guide](./SSH_SETUP.md)** - Follow this guide to set up SSH authentication or use a Personal Access Token.

### Quick Start

1. **Clone this repository:**
   ```bash
   git clone git@github.com:iamthetonyb/lunas-os.git
   cd lunas-os
   ```

2. **Add your files:**
   ```bash
   git add .
   ```

3. **Commit your changes:**
   ```bash
   git commit -m "Add my files"
   ```

4. **Push to GitHub:**
   ```bash
   git push origin main
   ```

If you encounter any authentication issues, refer to the [SSH Setup Guide](./SSH_SETUP.md).
