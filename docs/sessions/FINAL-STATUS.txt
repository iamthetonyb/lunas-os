🐛 TROUBLESHOOTING

If server won't start:
  1. Check NODE_ENV: echo $NODE_ENV
  2. Unset if needed: unset NODE_ENV
  3. Clean build: rm -rf .next
  4. Restart: pnpm dev

If Turbopack has issues:
  pnpm run dev:webpack

If port in use:
  lsof -i :4010 | grep LISTEN | awk '{print $2}' | xargs kill -9

If CSS not loading:
  1. rm -rf .next
  2. pnpm dev
  3. Hard refresh browser (Cmd+Shift+R)
